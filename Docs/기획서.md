# XR 게임 기획서: 애~앵

> 작성자: 전영호 · 플랫폼: Meta Quest (Android 빌드) · 선택 주제: **B. XR Interaction Toolkit을 활용한 VR 게임**

## 1. 게임 개요

### 1.1 한 줄 요약
> 자려고 누운 한밤중, 귓가를 맴도는 "애앵~" 소리에 잠을 못 이루는 나.
> 왼손엔 방 불 스위치, 오른손엔 파리채를 들고 모기를 최대한 빨리 잡아야 잠들 수 있는 VR 모기 사냥 게임.

### 1.2 목표 플레이어 경험
*   **소리로 쫓는 긴장감:** 불을 끄면 공간 음향으로 모기 소리가 왼쪽 귀, 뒤통수, 머리 위로 옮겨 다니고, 플레이어는 소리를 따라 고개를 돌림.
*   **불 켜기 / 끄기의 심리전:** "불 끄면 애앵~, 불 켜면 조용"이라는 여름밤의 공감 상황. 불을 켜서 벽에 붙은 모기를 숨죽여 노리다가, 들키면 다시 불을 끄는 반복.
*   **"딱!" 잡는 손맛:** 벽에 붙은 모기에게 숨죽여 다가가 파리채로 딱! 내리치는 손맛.

### 1.3 프로젝트의 핵심
*   **핵심 XR 메커니즘:**
    *   왼손에 늘 쥐고 있는 스위치로 불 On/Off
    *   오른손 트리거로 파리채를 쥐고 휘둘러 모기 잡기 (11/18: 맨손 잡기는 조작을 단순하게 하려고 뺌)
*   **게임 루프:** 불 꺼진 방에서 시작 → 소리로 모기 위치 파악 → 불 켜기 → 3초 뒤 모기가 벽에 붙음 → 조심스럽게 다가가 잡기 → (들키면 모기 사라짐 → 불 끄기 → 다시 등장) → 모두 잡으면 꿈나라 파티 / 시간이 다 되면 모기와 댄싱 파티 → 다음 판 자동 시작 (원하는 만큼 반복) → 왼손 스위치 길게 눌러 그만하기 → 결과 화면

## 2. 오브젝트 명세 및 XR 상호작용

### 2.1 XR Rig 및 플레이어 입력 (XR Origin / Controller)
*   **입력 방식:** 컨트롤러. 게임 속에서는 컨트롤러 대신 **손 모델**로 표시되고, 트리거를 누르면 검지가 접히는 애니메이션이 재생됨.
*   **이동 방식:** **이동 없음.** 플레이어는 침대 위 제자리에서 앉기 / 서기와 몸 돌리기만 함. 텔레포트, 연속 이동, 스냅 회전 모두 사용하지 않음 (멀미 요소 원천 차단).
*   **입력 로직:**

| 손 | 입력 | 동작 |
|---|---|---|
| 왼손 | (항상) | 무선 스위치를 쥐고 있는 상태로 고정 |
| 왼손 | 트리거(검지) 짧게 눌렀다 떼기 (1초 미만) | 방 불 On / Off 전환 |
| 왼손 | 트리거(검지) **1초 이상 길게 누르기** 또는 **메뉴 버튼(≡)** | `메인 화면으로 가시겠습니까?` 창 표시 (네 / 아니오). 메뉴 버튼을 다시 누르면 닫힘 |
| 오른손 | 책상 위 파리채에 손을 대고 트리거 **누르고 있기** | 파리채를 주먹에 쥔 상태 유지 |
| 오른손 | 트리거 떼기 | 파리채가 책상 위 제자리로 자동 복귀 |
| 오른손 | 레이 + 트리거 | 메뉴 / 결과 화면 UI 버튼 누르기 (게임 중에는 레이와 원거리 잡기 꺼짐) |

### 2.2 환경 (Environment)
*   **구성:** 한밤중의 작은 원룸 침실. **침대가 방 구석**에 붙어 있음.

```
        [ 앞: 열린 방 공간 ]
  ┌─────────────────────────┐
  │창문│                     │  ← 앞 벽: 책장 옆 LED 벽시계
  │(달 │   침대 발치          │  ← 오른쪽: 책상 (위에 파리채)
  │빛) │                     │
  │    │   😐 플레이어        │
  │    │   (머리 쪽)          │
  └────┴────────────────────┘
  ↑ 왼쪽 벽        ↑ 머리 쪽 벽 (뒤)
```

*   **플레이어 위치:** 침대 위, 머리 쪽 벽을 등지고 침대 발치를 바라보며 앉은 자세가 기본. 높은 곳을 노릴 때는 일어섬 (침대 위에 선 것으로 처리).
*   **벽 배치:**
    *   **뒤(머리 쪽):** 벽. 침대 헤드보드가 붙어 있음.
    *   **왼쪽:** 벽. 손이 닿는 가까운 거리이며, 창문으로 달빛이 들어옴.
    *   **오른쪽:** 책상. 책상 위에 파리채가 놓여 있음 (받침대 없음).
    *   **앞:** 침대 발치 너머로 열린 방 공간. 책장 옆 벽에 LED 디지털 시계.
*   **방 크기 제한:**
    *   앉기 / 서기만으로 모든 모기에 닿을 수 있도록, 모기는 **플레이어 머리 기준 반경 약 1.2m 이내**에서 날아다님.
    *   **착지 지점은 손이 닿는 범위(머리 기준 0.3~0.9m)에만** 둠 (11/18 결정: 이동 없이 침대에 고정, 조이스틱 이동은 멀미 때문에 넣지 않음). 높이는 0.6m~2.0m, 침대 이불 위는 예외로 0.3m부터.
*   **착지 지점 배치:** 침대 자리에서 사방으로 광선을 쏴서, 손이 닿는 벽과 가구 표면에 자동으로 배치함 (가구는 실제 메쉬 모양 기준).
    *   **왼쪽 벽, 창문, 앞쪽 이불 위, 오른쪽 책상과 스탠드 주변**
    *   **머리 쪽 벽(등 뒤):** 앉은 자세로는 노리기 어려우므로 **착지하지 않음.** 대신 불 꺼진 상태에서 모기가 뒤통수 쪽을 지나가며 소리를 내는 연출에만 사용함.
*   **조명:**
    *   **불 끈 상태:** 창으로 들어오는 푸른 달빛(Directional Light) + 낮은 Ambient. 사람의 **암순응 상태**처럼 방의 윤곽과 가구 구조는 대략 보이지만, 모기 같은 작은 물체는 잘 안 보이는 밝기.
    *   **불 켠 상태:** 천장 형광등(Point / Area Light)으로 방 전체가 밝아짐. 켜질 때 형광등이 짧게 깜빡이는 연출.
*   **물리:** 벽, 천장, 가구에 Collider 부착. 모기 착지 지점(Landing Point)을 미리 여러 곳 배치함.

### 2.3 상호작용 오브젝트 (Interactable Objects)

#### 파리채
*   XR Grab Interactable + Rigidbody (Kinematic). 오른손 전용.
*   **잡기:** 책상 위 파리채에 손을 대고 트리거를 누르고 있는 동안만 잡힘. Select 입력을 Grip 대신 트리거로 지정함. 잡으면 손 모델의 주먹 안에 쥐어짐.
*   **놓기:** 트리거를 떼면 Throw On Detach를 끄고, 0.2초 동안 책상 위 제자리로 부드럽게 돌아감 (Lerp).
*   **잡기 판정:** 채 머리 영역에 모기가 닿고, 휘두르는 속도가 **파리채 3.5m/s, 신문지 2.5m/s 이상**일 때 성공 (11/18: 1.5m/s 는 그냥 움직여도 넘어서 올림. 11/19: 신문지 3.0 → 2.5). 거리 제한 없음.

#### 왼손 스위치
*   왼손 모델에 고정된 무선 스위치 소품. 별도로 잡을 필요 없음.
*   **짧게 누르기:** 트리거를 1초 미만으로 눌렀다 **뗄 때** 방 불 On / Off 전환. 딸깍 소리와 짧은 진동.
*   **길게 누르기:** 트리거를 1초 이상 누르고 있으면 메인 복귀 확인 창이 뜸 (4.2 참고). 이때는 불이 전환되지 않음.
*   누르는 순간이 아니라 떼는 순간에 불을 전환해야 짧게 / 길게 누르기가 구분됨.

#### ~~오른손 맨손 잡기 / 거리별 잡기 구간~~ (11/18 제외)
*   처음 기획은 거리별로 맨손(근거리)과 파리채(원거리)를 나눠 쓰는 것이었지만, 오른손 트리거가 "파리채 잡기"와 "맨손 잡기"로 겹쳐 헷갈리고 일정도 빠듯해서 **파리채로만 잡도록 단순화함.**
*   코드(HandCatch)는 남겨 두고 꺼 둠. 다시 켜면 근거리 0.4m 안은 맨손, 0.7m 밖은 파리채로 나뉨.

#### 모기
*   **크기:** 눈에 보이도록 실제보다 2~3배 크게 만들고, 판정용 Sphere Collider는 그보다 넉넉하게 잡음.
*   **사운드:** AudioSource Spatial Blend = 1 (3D 사운드), 거리에 따른 볼륨 감쇠.
*   **상태(FSM):**

| 상태 | 조건 | 행동 |
|---|---|---|
| `Fly` | 불 꺼짐 | 방 안을 계속 랜덤 비행하며 "애앵~" 소리를 냄. 휘두른 무기에 걸려도 확률로만 잡힘 (파리채 20%, 신문지 35%: 작은 신문지는 맞히기 어려운 대신 맞으면 잘 잡힘). 앉아 있을 때 치면 확실히 잡힘. |
| `Approach` | 불 꺼짐, 랜덤 | 몇 초간 플레이어 머리 주변을 맴돌다 다시 `Fly`로 돌아감. 귓가에서 소리가 커지는 긴장감 연출 (파리채로 잡을 수도 있음). |
| `ToWall` | 불 켜짐 | 3초 동안 계속 날다가, 가장 가까운 착지 지점으로 이동. |
| `Landed` | 벽에 착지 | 소리를 멈추고 가만히 붙어 있음. 이때 조심스럽게 다가가 잡음. |
| `Escape` | `Landed` 중 손이나 파리채가 빠르게 움직임 | 날아올라 사라지고 자막 `모기가 사라졌습니다` 표시. |
| `Hidden` | 사라진 상태 | 불이 켜져 있는 동안 계속 숨어 있음. 불을 끄고 **5초가 지나면** 랜덤 위치에서 소리와 함께 다시 `Fly`로 등장. |

*   **눈치 판정 (`Landed` → `Escape`):**
    *   모기 반경 **0.6m 안**에서 오른손이나 파리채가 **1.0m/s 이상**으로 움직이면 눈치챔.
    *   눈치챈 뒤 실제로 날아오르기까지 **0.25초의 반응 지연**이 있음. 천천히 다가가서 마지막에 빠르게 내리치면 잡을 수 있음.
    *   수치는 모두 초기값이며, 헤드셋 테스트로 조정함.

## 3. 게임 시스템

### 3.1 판 구조
*   **며칠 밤 같은 스테이지 구분 없음.** 플레이어가 원하는 만큼 계속 플레이함.
*   **한 판:** 모기가 **첫 판 5마리, 판마다 1마리씩 늘어 최대 8마리** 등장하고 (11/18 헤드셋 테스트: 3마리는 35초 안에 끝나서 늘림), 제한 시간(초기값 3분)이 주어짐. 벽시계가 새벽 1시에서 아침 7시로 흘러가는 것으로 표현함 (게임 1시간 = 현실 30초). 메인 화면에서는 시계가 실제 현재 시각을 보여줌.
*   한 판이 끝나면 짧은 파티 연출 후 다음 판이 자동으로 시작됨.
*   **첫 판 튜토리얼:** 게임을 시작한 첫 판에만 자막으로 순서를 안내함.
    1. 불 켜기
    2. 책상 위 파리채 잡기 (오른손 트리거를 누르고 있기)
    3. 벽에 붙은 모기에게 천천히 다가가 파리채로 잡기
*   **고유 환경 연출:**
    *   창문으로만 들어오는 달빛 (벽에 창 모양 빛)
    *   **해 뜨기:** 게임 시각 5시 30분(판 끝나기 45초 전)부터 창밖 하늘이 붉은 새벽 → 아침으로 바뀌고, 달빛 대신 붉은 해가 창문으로 낮게 들어와 점점 밝아짐 (남은 시간을 시계 말고 빛으로도 느끼게)
    *   벽 LED 디지털 시계가 새벽 시각으로 흘러감
    *   불을 켤 때 형광등 깜빡임 (1초 이내)

### 3.2 판 결과 조건
*   **실패 / 게임 오버 없음.** 모기에게 물리는 요소도 없음.
*   **한 판이 끝나는 조건 (둘 중 먼저 일어나는 것):**
    *   **꿈나라 파티:** 그 판의 모기를 모두 잡음 → 화면이 서서히 어두워지며 잠드는 연출.
    *   **모기와 댄싱 파티:** 모기를 다 못 잡고 아침 7시가 됨 → 알람이 울리며 판 종료. 못 잡은 모기는 못 잡은 대로 넘어감.
*   각 파티 횟수를 누적해서 기록함.
*   ※ 파티 이름, 조건, 연출 상세는 추후 확정 예정.

### 3.3 씬 간 데이터 전달 (GameManager 활용)
*   **`Play Scene` ➔ `Result Scene`:**
    *   전달 데이터: `꿈나라 파티 횟수(int)`, `모기와 댄싱 파티 횟수(int)`
    *   방식: `DontDestroyOnLoad`가 적용된 GameManager에 저장한 뒤 결과 씬에서 불러옴. 메인 화면으로 돌아가면 횟수 초기화.

## 4. 씬 구성 및 UI

> XR에서는 화면에 고정된 HUD 대신 World Space Canvas(공간에 띄운 패널, 손목 UI)를 사용하고, 버튼은 오른손 레이로 누름.

### 4.1 메인 화면 (Menu Scene)
*   **배경:** 불이 켜진 침실.
*   **UI 요소:** 타이틀 "애~앵", Start 버튼, Exit 버튼 (11/18: 제작자 이름 뺌)
*   **UI 위치:** 플레이어 정면 약 2m 앞 World Space 패널
*   **기능:** Start → 무기 선택창 (파리채 / 신문지 카드: 이름, 정사각형 이미지, 스펙[길이, 치는 면, 공중 저격 확률, 스윙 속도], 시작 버튼 + 뒤로) → 카드의 시작을 누르면 그 무기로 플레이 씬 로드. Exit → 앱 종료

### 4.2 게임 플레이 화면 (Play Scene)
*   **인게임 UI:**
    *   **왼손 손목 UI:** 이번 판에 잡은 모기 수 `( 2 / 3 )`, 지금까지의 꿈나라 파티 / 모기와 댄싱 파티 횟수
    *   **벽 디지털 시계 (책장 옆):** 남은 제한 시간을 새벽 시각(AM 01:00 → 07:00)으로 보여주는 게임 속 오브젝트. 메인 화면에서는 실제 시각
    *   **자막:** 시야 하단에 부드럽게 따라오는 패널(Lazy Follow). `모기가 사라졌습니다`, 튜토리얼 안내 등을 2초간 표시.
*   **판 종료 시:** 정면에 `다 잡았다! 오늘 밤은 꿀잠이다!` 또는 `못 잡았다... 오늘 하루는 글렀다...` 텍스트(두 줄)를 2초간 띄운 뒤 다음 판 시작 (11/18: "꿈나라 파티!" / "모기와 댄싱 파티!"에서 바꿈. 아래 "꿈나라 파티" / "모기와 댄싱 파티"는 코드 속 이름으로 그대로 씀)
*   **메인 복귀 확인 창:**
    *   왼손 트리거를 1초 이상 길게 누르거나 왼쪽 메뉴 버튼(≡)을 누르면 `Time.timeScale = 0`, 모기 소리 정지, 정면에 `메인 화면으로 가시겠습니까?` 창 표시.
    *   오른손 레이로 `네` / `아니오` 선택.
    *   `아니오` → 창이 닫히고 게임 재개.
    *   `네` → 결과 화면으로 이동.

### 4.3 결과 화면 (Result Scene)
*   **진입:** 메인 복귀 확인 창에서 `네`를 눌렀을 때.
*   **결과 UI:** 정면 패널에 이번 플레이의 누적 기록 표시.
    *   `꿀잠 N번` (다 잡은 판)
    *   `밤샘 N번` (7시가 된 판)
*   **메인으로:** 결과 화면이 뜨고 **3초가 지난 뒤** 컨트롤러의 아무 버튼이나 누르면 메인 화면으로 이동. 3초가 지나면 `아무 버튼이나 눌러 메인으로` 안내 문구가 깜빡이며 나타남. (3초 대기는 기록을 확인하기 전에 실수로 넘어가는 것을 막기 위함)

## 5. 상호작용 피드백

### 5.1 시각 피드백 (Visual Effect)
*   **모기 잡았을 때:** "딱!" 텍스트 팝업 + 작은 파티클. 모기는 납작해진 채로 잠시 남았다가 사라짐.
*   **헛스윙:** 파리채 끝에 바람 궤적(Trail Renderer)만 표시.
*   **모기가 눈치챘을 때:** 날아오르기 직전 0.25초 동안 날개를 파르르 떠는 애니메이션 (반응 지연을 플레이어에게 보여주는 신호).
*   **불 On / Off:** 형광등 깜빡임 후 점등 / 달빛만 남는 어두운 방으로 전환.

### 5.2 청각 피드백 (Audio Effect)
*   **BGM:** 없음 또는 아주 작은 밤 환경음 (귀뚜라미, 시계 초침). 모기 소리가 잘 들리게 하는 것이 우선.
*   **SFX:**
    *   모기: "애앵~" 루프 (3D 공간 음향, 접근 시 피치와 볼륨 상승)
    *   모기 재등장: 불 끄고 5초 뒤 멀리서부터 점점 커지는 "애앵~"
    *   잡았을 때: 경쾌한 "딱!"
    *   헛스윙: "휙"
    *   제한 시간 종료: 아침 알람 소리
    *   스위치: 딸깍
    *   파리채가 책상 위로 돌아갈 때: 가벼운 "탁"

### 5.3 햅틱 피드백 (Haptic)
*   모기 잡았을 때: 오른손에 강하고 짧은 진동
*   파리채 잡을 때 / 책상 위로 돌아갈 때: 오른손에 약한 진동
*   스위치 On / Off: 왼손에 짧은 클릭 진동
*   모기가 아주 가까이 접근했을 때: 아주 약하게 떨리는 진동 (긴장감)

## 8. 리스크 및 대응

| 리스크 | 대응 |
|---|---|
| 눈치 판정 때문에 파리채로 잡기가 거의 불가능함 | 반응 지연(0.25초)과 눈치 반경(0.6m)을 헤드셋에서 조정. 날개 떠는 신호로 플레이어가 타이밍을 배우게 함. |

| 공간 음향이 에디터와 헤드셋에서 다르게 들림 | 2일차에 헤드셋으로 소리 위치감을 먼저 테스트함. |

| 불 켜기(짧게)와 메인 복귀(길게)가 섞여 오작동함 | 불은 트리거를 뗄 때 전환하고, 1초가 넘으면 불 전환을 취소함. |
