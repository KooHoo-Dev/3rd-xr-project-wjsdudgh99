## 0. 다른 PC(집)에서 이어서 하기

1. **Unity Hub**에서 **6000.3.15f1**을 설치하고, 모듈은 **Android Build Support**와 그 아래 **OpenJDK**, **Android SDK & NDK Tools**를 체크합니다.
   - Android 모듈이 없으면 XR Plug-in Management에 안드로이드 탭이 안 보입니다.
2. `git clone https://github.com/KooHoo-Dev/3rd-xr-project-wjsdudgh99.git` → Unity Hub에서 프로젝트를 엽니다. 첫 실행은 Library를 새로 만드느라 오래 걸립니다.
3. `File > Build Profiles` → **Android** → **Switch Platform**을 누릅니다. 플랫폼 설정은 Library에 저장되므로 PC마다 다시 해야 합니다.
4. `Assets/AeAeng/test.unity`를 엽니다. 현재 빌드 목록에 있는 유일한 씬입니다.
5. Quest를 USB로 연결하고 헤드셋 안에서 **USB 디버깅 허용**을 누릅니다 ("이 컴퓨터에서 항상 허용" 체크).
   - 연결 확인: `"<Unity 설치 경로>/Editor/Data/PlaybackEngines/AndroidPlayer/SDK/platform-tools/adb.exe" devices`
   - `device`로 나오면 정상, `unauthorized`면 헤드셋에서 허용을 안 누른 것, 아무것도 안 나오면 케이블(충전 전용인지)이나 개발자 모드를 확인합니다.
6. Build Profiles → Run Device에서 Quest 선택 → **Build And Run**

## 3. 만든 파일

```
Assets/AeAeng/
├─ test.unity                         ← 현재 작업 씬 (빌드 목록에 등록됨)
├─ AeAeng.unity                       ← 빈 씬 (나중에 메인/플레이 씬으로 쓸 예정)
├─ Materials/TestBedroom/*.mat        ← 테스트 침실 머티리얼 (URP Lit / Unlit)
└─ Scripts/
   ├─ Lighting/RoomLightController.cs ← 방 불 On/Off, 깜빡임, Ambient 제어
   ├─ Input/LightSwitchInput.cs       ← 왼손 트리거 짧게 = 불 전환 / 1초 이상 = onLongPress
   ├─ Debug/LightingTuner.cs          ← (테스트용) 헤드셋 안에서 밝기 조절
   └─ Editor/TestBedroomBuilder.cs    ← 메뉴 AeAeng > Build Test Bedroom
```

### RoomLightController
- **불 끔:** 달빛 Directional(푸른색, 그림자 없음) + 아주 어두운 Flat Ambient
- **불 켬:** 천장 Point Light + 밝은 Ambient + 천장 패널 색 변경. 켜질 때 `flickerPattern` 순서대로 깜빡입니다 (총 약 0.35초).
- URP는 ambient probe(SH)를 읽기 때문에 `RenderSettings.ambientProbe`를 직접 갱신합니다.
- `LightChanged(bool)` 이벤트가 있어서, 모기 FSM이 불 상태를 구독하는 데 쓰면 됩니다.
- `IsOn`, `Toggle()`, `SetLight(bool on, bool withFlicker)`

### LightSwitchInput
- 바인딩: `<XRController>{LeftHand}/{TriggerButton}`, 에디터 테스트용 키보드 `L`
- 기획서대로 **떼는 순간**에 불을 전환하고, 1초가 넘으면 전환을 취소한 뒤 `onLongPress`(UnityEvent)를 호출합니다.
- `Time.unscaledTime`을 쓰므로 `timeScale = 0`(메인 복귀 확인 창)에서도 동작합니다.
- `onLongPress`는 아직 아무것도 연결하지 않았습니다. 11/20에 메인 복귀 확인 창을 연결합니다.
- 햅틱과 딸깍 소리는 아직 없습니다.

### LightingTuner (테스트용, 최종 빌드 전에 삭제)
| 헤드셋 | 키보드 | 동작 |
|---|---|---|
| 왼손 트리거 (짧게) | L | 불 켜기 / 끄기 (LightSwitchInput) |
| 오른손 B / A | `=` / `-` | 선택한 값 올리기 / 내리기 |
| 왼손 X | N | 항목 바꾸기: Ambient → Moon → Ceiling |
| 왼손 Y | H | 초록 안내 글씨 숨기기 (녹화용) |

- 값을 바꿀 때마다 `[LightingTuner] ...` 로그가 찍힙니다. 헤드셋에서 바꾼 값은 아래처럼 logcat으로 확인할 수 있습니다.
  `adb logcat -d -s Unity:I | grep LightingTuner`
- 안내 글씨는 카메라 자식인 `TunerLabel`(TextMeshPro)입니다.

### TestBedroomBuilder (에디터 메뉴)
- `AeAeng > Build Test Bedroom`: 지금 열린 씬에 `TestBedroom`을 만듭니다. 이미 있으면 지우고 다시 만듭니다.
- XR Origin (Starter Assets 프리팹)이 없으면 추가하고, **Tracking Origin = Floor**로 설정합니다. **이동/회전/텔레포트/중력/등반 Provider는 모두 끕니다** (기획서의 "이동 없음").
- XR 카메라: 배경 검정 Solid Color, Near Clip 0.01
- XR Origin 바깥의 카메라와 기존 Directional Light는 비활성화합니다.
- ⚠️ 다시 실행하면 씬에서 손으로 바꾼 TestBedroom 내용이 사라집니다. 조명 기본값은 스크립트에도 반영해 두었습니다.
- **문 벽 (11/17 추가):** 씬에 `Free Wood Door Pack` 문 프리팹이 있으면, 가장 가까운 벽을 문 크기(Renderer Bounds)에 맞춰 구멍 뚫린 벽 3조각(`Side_A`, `Side_B`, `Lintel`)으로 만듭니다.
  - 벽이 문틀을 1cm씩 덮도록 구멍을 약간 작게 뚫습니다.
  - 문은 벽 두께 가운데로 자동으로 옮겨집니다. 벽과 나란한 방향의 위치와 높이는 그대로 둡니다.
  - 문은 TestBedroom 밖(씬 루트)에 두므로 다시 실행해도 지워지지 않습니다. 문을 옮긴 뒤 메뉴를 다시 실행하면 구멍도 따라 옮겨집니다.

## 4. 테스트 침실 배치

XR Origin = 원점 (0, 0, 0), 플레이어는 **+Z(침대 발치)**를 바라봅니다. 단위는 m입니다.
방은 **3m × 3m 정사각형**입니다 (`RoomSize` 상수로 변경 가능). 처음엔 4m였지만, 플레이어가 움직이지 않고 모기 활동 반경도 1.3m라 빈 공간이 너무 많아서 11/17에 줄였습니다.

| 요소 | 위치 |
|---|---|
| 뒤 벽 (머리 쪽, 헤드보드) | z = -0.45 |
| 왼쪽 벽 (창문) | x = -0.6, 창문 중심 (y 1.45, z 1.5), 크기 0.9 × 1.0 |
| 오른쪽 벽 (문) / 앞 벽 | x = 2.4 / z = 2.55. 문 `Door_6_Yellow`는 오른쪽 벽 z = 1.5 근처 (문짝 1.0 × 2.1m, 문틀 약 1.12 × 2.16m, 벽 구멍 1.104 × 2.147m) |
| 천장 | y = 2.4, 형광등 패널과 Point Light는 (1.1, 2.25~2.38, 1.3) |
| 침대 | x -0.6~0.5, z -0.45~1.6, 매트리스 윗면 약 0.5 |
| 협탁 | 중심 (0.8, 0.25, 0.0). 위에 빨간 디지털 시계(침대 쪽을 봄)와 스탠드 |
| 파리채 받침대 (자리만) | (0.75, 0~0.9, 0.45) |
| 모기 대용 구 5개 (지름 3cm) | 왼쪽 벽 낮은 곳/높은 곳, 이불 위, 스탠드 갓, 천장 |
