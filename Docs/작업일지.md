   - 연결 확인: `"<Unity 설치 경로>/Editor/Data/PlaybackEngines/AndroidPlayer/SDK/platform-tools/adb.exe" devices`

### 0-1. PC를 바꿔서 이어 할 때 주의사항 (학원 ↔ 집)

- **시작하기 전에 항상 pull, 끝나면 항상 커밋·푸시.** 다른 PC에 남은 작업은 git으로만 옮겨집니다.
- **pull 전에 "커밋 안 된 같은 이름 파일"을 지웁니다.** 저장소에 새로 올라온 파일이 내 PC에 커밋 안 된 채로 있으면 `untracked working tree files would be overwritten` 오류로 pull이 멈춥니다.
  - ⚠️ **학원 PC (11/18):** `Assets/JaneArtWork/`와 `Assets/JaneArtWork.meta`가 커밋 안 된 채로 남아 있습니다. 11/17 집 PC에서 커밋했으므로, 지우고(또는 다른 곳으로 옮기고) pull하면 같은 파일이 내려옵니다.
- **Unity가 자동으로 바꾼 설정 파일은 Discard해도 됩니다.** `NotoSansKR-Regular SDF.asset`, `OpenXRPackageSettings.asset`, `TargetRing.playable`, `QualitySettings.asset`, `URPProjectSettings.asset`, `GraphicsSettings.asset`, `ProjectSettings.asset`, `Mobile_RPAsset.asset`, `UniversalRenderPipelineGlobalSettings.asset` 등은 대부분 줄바꿈이나 순서만 바뀐 것입니다. pull이 충돌하면 받은 버전을 씁니다.
- **씬에 새 에셋을 쓰면 그 에셋 폴더도 같이 커밋합니다.** 11/17에 침대(`JaneArtWork`)를 커밋하지 않아서 집 PC에서 침대가 안 보였습니다. 커밋 전에 씬이 참조하는 GUID가 저장소에 다 있는지 확인합니다 (`Unity 내장 0000…`, TextMeshPro `9541d86e…`, URP 조명 `474bcb49…`는 패키지라 없어도 정상).
- **처음 빌드할 때 `Application update incompatible` 창 → Yes.** PC마다 디버그 서명 키가 달라서, 다른 PC에서 설치한 앱을 지우고 새로 설치합니다. PlayerPrefs가 지워지므로, 저장 기능(최고 기록 등)을 넣으면 두 PC가 같은 키스토어를 쓰도록 바꿔야 합니다.
- **Quest 연결:** 처음 연결하는 PC는 헤드셋에서 USB 디버깅 허용이 필요합니다. 집 PC는 11/16에 케이블을 데이터 케이블로 바꾸고 허용 완료.
- **Platform(Android)과 빌드 설정은 PC마다 따로입니다** (Library에 저장). Switch Platform을 다시 해야 할 수 있습니다.
- **쓰지 않는 폴더:** 집 PC의 `Assets/GhostlyHand/`는 커밋하지 않았습니다 (셰이더뿐이라 안 씀). 학원 PC에는 없어도 됩니다.
- **Claude와 이어서 작업할 때:** 대화 내용은 PC 사이에 이어지지 않습니다. "작업일지 보고 이어서 하자"로 시작하면 됩니다.

### HandBuilder / HandPose / GhostHand (11/17)
- **손 모델:** XR Hands 1.8.1 샘플(HandVisualizer)의 `LeftHand.fbx`, `RightHand.fbx`를 `Models/Hands/`로 복사 (import 설정은 원본 그대로, GUID만 새로). 뼈 이름 `L_/R_` + `Wrist`, `IndexProximal` 등
- **`AeAeng > Build Hands`:** `Prefabs/LeftHand.prefab`, `RightHand.prefab` 생성 → XR Origin의 `Left/Right Controller` 아래에 붙이고 `Left/Right Controller Visual`(컨트롤러 모델)을 끔. 다시 실행해도 이미 붙은 손의 위치는 안 바꿈
  - 프리팹 좌표: 원점 = 손목, +Z = 손가락, +Y = 손등 (모델을 손 모양에서 계산해 돌림)
  - 컨트롤러 기준 처음 위치: 손목 (0, -0.035, -0.11), 손등이 바깥쪽. 손가락 각도는 11/17 헤드셋 확인 결과 20°면 손가락이 위를 향해서 **45°**로 바꿈. `AeAeng > Reset Hand Position`으로 씬의 손을 이 기본값으로 되돌림
  - **HandOffsetTuner (TEST)** (테스트용, 최종 빌드 전에 삭제): 헤드셋 안에서 조이스틱으로 양손 위치를 대칭으로 조정. 오른쪽 스틱 위아래 = pitch, 좌우 = 앞뒤(z) / 왼쪽 스틱 위아래 = 높이(y), 좌우 = roll. 값은 `adb logcat -d -s Unity:I | grep HandTuner`로 읽어서 HandBuilder 기본값에 반영
- **RayVisibility** (XR Origin 루트): 컨트롤러 레이(`LineVisual`)와 Poke Interactor의 회색 점(`Poke Point Affordances`)을 게임 중에는 숨김 (`showRays = false`). 메뉴/결과 화면에서는 `SetVisible(true)`
  - 미리보기: `Temp/HandPreview/` (펼친 손 / 쥔 손, 회색 재질)
- **HandPose:** 손가락마다 소스(Fixed / Trigger / Grip)와 접힘 범위 min~max. 접는 축은 Awake에서 손 모양(손목, 검지·새끼 뿌리)으로 계산 → `AngleAxis(curl × 마디 각도)`
  - 마디 최대 각도: 손가락 70° / 90° / 60°, 엄지 20° / 35° / 45°
  - 왼손: 엄지 0.35, 중지·약지·새끼 0.8 고정, 검지 트리거 0.15 → 0.65
  - 오른손: 엄지·검지는 트리거 (0.1 → 0.7 / 0.95), 중지·약지·새끼는 `TriggerOrGrip` (기본 0.4~0.5로 살짝 말림 → 그립만 쥐면 80%, 트리거면 주먹). 11/17 헤드셋에서 손가락이 너무 쫙 펴져 보여서 바꿈
  - 에디터 테스트 키: 왼손 트리거 L, 오른손 트리거 K, 오른손 그립 J. 입력은 `<XRController>{LeftHand}/trigger` 등을 직접 읽음
- **GhostHand 셰이더** (`Shaders/GhostHand.shader`, 재질 `Materials/Hands/GhostHand.mat`): 1패스 깊이만, 2패스 `Blend One One`로 fill + fresnel 가장자리 빛. Transparent 큐, 그림자 없음. 색은 `_RimColor`(0.25, 0.69, 0.80), `_FillColor`, `_RimPower` 2, `_RimScale` 1

### WallClockBuilder / LedClock / RoundClock (11/17)
- **모양:** 48 × 15 × 2.8cm 검정 둥근 사각 본체, 삼각형 424개. 원점 = 뒷면 가운데(벽에 닿는 면), 화면은 -Z를 봄 → 회전 0이면 앞 벽에 걸림.
  - 큰 숫자 `HH:MM`(높이 10cm, 8° 이탤릭) + `AM/PM` + 오른쪽에 요일(`TUE`), `MONTH DATE`, 작은 숫자 `MM/DD`
  - 숫자는 폰트가 아니라 **세그먼트마다 MeshRenderer 하나**(뾰족한 육각형)이고, `LedClock`이 켜짐/꺼짐 재질만 바꿉니다.
  - LED 켜짐은 **Unlit**(불을 꺼도 같은 밝기), 꺼짐은 **Lit**(앞면과 같은 빛을 받아서 살짝 붉게만 보임)
  - 요일과 라벨은 TextMeshPro (TMP 기본 폰트, 자동 크기)
  - 아래로 퍼지는 따뜻한 빛: `Underglow` 스포트라이트 (각도 150°, 범위 0.6m, 세기 0.25, 그림자 없음). 너무 밝거나 Quest 부담이 되면 이 오브젝트만 끕니다.
  - 미리보기는 `Temp/WallClockPreview/`. 미리보기에는 TMP 글씨가 안 나오지만 씬에서는 보입니다.
- **LedClock:** 기본은 실제 현재 시각(`useRealTime`). `SetTime(DateTime)`을 부르면 그 시각을 보여줌. `:`은 1초에 한 번 깜빡임(unscaledTime). 12시간제, 시와 월의 앞자리 0은 끔.
- **RoundClock** (`AeAeng > Add Round Clock (Game Time)`으로 씬에 추가):
  - 판 진행 중: 현실 `roundSeconds`(180초) 동안 AM `startHour`(1) → `endHour`(7). **게임 1시간 = 현실 30초, 게임 1분 = 현실 0.5초**
  - 7:00이 되면 멈추고 `onMorning`(UnityEvent) 호출 → 나중에 모기와 댄싱 파티 / 알람에 연결
  - `StartRound()`, `StopRound()`(실제 시각으로 되돌림), `Remaining`, `Progress01`, `GameTime`
  - `Time.deltaTime` 기준이라 timeScale = 0(메인 복귀 창)이면 게임 시간도 멈춤
  - `clocks`를 비워 두면 씬의 LedClock을 모두 찾아서 씀
  - `startOnPlay = true`는 GameManager가 생기기 전 테스트용입니다. 11/20 GameManager를 만들면 끄고 `StartRound()`를 GameManager에서 부릅니다.
  - **메인 화면**: RoundClock을 두지 않거나 `StopRound()` 상태 → 시계는 실제 시각

## 7. 자주 쓰는 명령

```bash
# adb 경로 (Unity 내장)
ADB="C:/Program Files/Unity/Hub/Editor/6000.3.15f1/Editor/Data/PlaybackEngines/AndroidPlayer/SDK/platform-tools/adb.exe"
```
